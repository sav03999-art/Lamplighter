# Фонарщик — Нисхождение

3D action-roguelike в браузере на Three.js r160. Вся логика — в `index.html`, модели — в `assets/`, звук и музыка синтезируются в коде.

**Играть:** через GitHub Pages. Если открыть `index.html` локально, модели подгрузятся с jsDelivr (нужен интернет); без сети игра переключится на упрощённые процедурные модели.

## Механики
- **4 оружия** с разным темпом и заряженной атакой (удерживайте удар): клинок — огненный выпад, двуручник — вихрь, кинжал — шаг тени за спину, секира — удар о землю.
- **Стихии** Пламя, Иней, Гроза через дары на оружие, искру, рывок или вспышку. Реакции: Пар, Раскол, Перегрузка.
- **Отражение**: удар оружием отбивает вражеские снаряды обратно.
- **Щиты**: големы и элитные враги блокируют удары спереди — заходите со спины или бейте тяжёлым ударом.
- **Элиты** со свойствами: Щит, Стремительный, Взрывной, Некромант, Делящийся.
- **Бочки** взрываются, **ящики** дают угли, **серия** убийств без урона увеличивает добычу.

## Управление
| Действие | Клавиатура / мышь | Геймпад |
|---|---|---|
| Движение | WASD / стрелки | левый стик |
| Удар оружием (удерживать — заряд) | ЛКМ / J | X / RB |
| Искра | ПКМ / K | B / RT |
| Рывок | Пробел / Shift | A / LB |
| Вспышка | Q / L | Y / LT |
| Взаимодействие | E | Y |
| Пауза | Esc | Start |

На телефоне — виртуальный стик и кнопки.

## Содержимое
- 3 яруса, процедурные комнаты, выбор награды за дверью
- 6 типов врагов, элитные версии, 3 босса с фазами
- 28 даров, лавка, привал, испытания
- Вечные улучшения у Очага за пепел (сохраняются в браузере)

## Модели
Персонажи (с анимациями) и детали подземелья — паки KayKit от Kay Lousberg (www.kaylousberg.com), лицензия CC0. Подробности — в `assets/LICENSE.txt`.
